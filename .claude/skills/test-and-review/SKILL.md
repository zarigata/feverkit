# Test And Review

Use this skill when the task matches its purpose. Adapt to the project; it is guidance, not executable code.

1. Reproduce the current behavior or failure before editing.
2. Write focused tests or a repeatable manual test plan appropriate for the stack.
3. Make the smallest correct implementation and run checks.
4. Review: edge cases, security, resource usage, regressions, accessibility and logs.
5. State exactly which commands passed, failed or could not run. Never manufacture success.
6. For UI changes, use actual browser/device screenshots where available; for games, test controls and rendering.
7. Report changed files, impact and rollback.

**Deliverable:** short evidence-based findings, changed files (if any), tests executed, risks, and next steps.
