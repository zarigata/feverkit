# Application Review

Use this skill when the task matches its purpose. Adapt to the project; it is guidance, not executable code.

1. Verify employer, opening status, location, visa/work eligibility and direct application link.
2. Compare requirements with **real** applicant experience; do not fabricate credentials.
3. Prepare tailored resume and evidence-based cover letter; preserve accurate dates and scope.
4. Track follow-ups and avoid duplicate submissions.
5. Never submit applications or contact recruiters without explicit authorization.

**Deliverable:** short evidence-based findings, changed files (if any), tests executed, risks, and next steps.
