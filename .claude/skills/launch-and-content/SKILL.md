# Launch And Content

Use this skill when the task matches its purpose. Adapt to the project; it is guidance, not executable code.

1. Define target audience, problem, value proposition and a measurable success criterion.
2. Review website copy, accessibility, performance, social cards and discovery metadata.
3. Prepare demo assets, onboarding, docs, support and pricing clarity.
4. Avoid artificial reviews, false statistics, deceptive endorsements and spam campaigns.
5. Test conversion funnel, analytics consent and unsubscribe preferences where relevant.
6. Launch only after security and production readiness review.

**Deliverable:** short evidence-based findings, changed files (if any), tests executed, risks, and next steps.
