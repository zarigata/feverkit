# Frontend Quality

Use this skill when the task matches its purpose. Adapt to the project; it is guidance, not executable code.

1. Inventory current design tokens, layout rules, and brand identity; preserve recognizable design unless asked otherwise.
2. Define typography scale, colors, spacing, responsive breakpoints and component states.
3. Check keyboard access, labels, contrast, focus management, reduced motion and mobile sizes.
4. Validate loading, empty, error, success and real-data states; avoid mock data in production.
5. Capture rendered screenshots at desktop/mobile sizes and test interactions; screenshot reviews must be honest.
6. Audit generated copy for repetitive filler and confusing language; improve clarity without inflating claims.
7. Compare with prior state and record performance and accessibility issues.

**Deliverable:** short evidence-based findings, changed files (if any), tests executed, risks, and next steps.
