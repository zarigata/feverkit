# Api Contracts

Use this skill when the task matches its purpose. Adapt to the project; it is guidance, not executable code.

1. Define data entities and ownership boundaries.
2. Document request/response schemas, errors, pagination, idempotency and versioning.
3. Define authentication and authorization per endpoint, including cross-tenant negative tests.
4. Validate all external inputs and protect API keys in server-side environment configuration.
5. Add migration plan and tests covering failure, retry, timeout and partial success.
6. Ensure monitoring covers errors and latency without logging sensitive payloads.

**Deliverable:** short evidence-based findings, changed files (if any), tests executed, risks, and next steps.
