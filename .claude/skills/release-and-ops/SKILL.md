# Release And Ops

Use this skill when the task matches its purpose. Adapt to the project; it is guidance, not executable code.

1. Identify environment targets, secrets, data migrations and dependencies.
2. Validate reproducible builds, immutable versions and container security.
3. Run tests, static checks and health checks before release.
4. Prepare backups and rollback; label irreversible changes.
5. Include metrics, logs, alerting and an incident owner; minimize exposed ports.
6. Deploy only with explicit authorization and report concrete post-deploy evidence.

**Deliverable:** short evidence-based findings, changed files (if any), tests executed, risks, and next steps.
