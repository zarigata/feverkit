# Game Testing

Use this skill when the task matches its purpose. Adapt to the project; it is guidance, not executable code.

1. Detect Godot, Unity, Rust or custom engine and inspect its native tooling.
2. Preserve existing controls, save formats, physics and network protocols unless changes were requested.
3. Test input mapping, physics time steps, movement, collisions, camera, gravity and multiplayer if present.
4. Test loading/streaming, rendering, transparent textures, shadows, LOD and resource usage.
5. Capture actual screenshots/video or use engine logs and automated scenes; never claim visual verification without seeing output.
6. Record game-breaking defects, reproduction and platforms; prioritize regressions before new content.

**Deliverable:** short evidence-based findings, changed files (if any), tests executed, risks, and next steps.
