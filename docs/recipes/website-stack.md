# Recipe: professional website and launch

Profiles: `core,fullstack,marketing,saas`

1. Audit brand voice, UI state consistency, navigation and SEO metadata.
2. Apply an anti-slop pass (e.g. Unslop as a **candidate**) and accessibility review.
3. Check Core Web Vitals, mobile behavior, structured data and link integrity.
4. Create honest demo assets and docs; avoid exaggerated claims.
5. Run privacy/security readiness before public launch.
6. Track meaningful outcomes without hidden tracking or spam.
