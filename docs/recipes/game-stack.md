# Recipe: AI-assisted game development

Profiles: `core,game,devops`

1. Identify engine (Godot/Unity/Rust) and native test tooling.
2. Architect asset pipeline, save format, world streaming and perf budgets.
3. Build a repeatable test scene for controller mappings, collisions, vehicle handling, gravity and camera behavior.
4. Compare screenshots of lighting, shadows, transparency and LOD before/after changes.
5. Prefer small engine-native utilities over installing entire generic agent swarms.
6. Test releases and packaging on each target OS. Preserve working features and asset attribution.

Example research repo: `javascript-tetris` is a **test fixture**, not a game-engine dependency.
